Parker Engine

一个从 Psych Engine 分支而来的《周五夜放克》（Friday Night Funkin'）引擎：内置 Lua、HScript、LScript(Luau)、Python 四种脚本语言，自带 Modchart 音符修饰器系统与移动端支持。

特色功能

Parker Engine 在 Psych Engine 的基础上主要扩展了脚本能力与音符特效系统。

四种脚本语言
Lua、HScript、LScript(Luau)、Python 并存，同一条歌曲里可以混用；脚本按目录自动加载，无需注册。
Modchart 修饰器
Schmovin'/Andromeda 风格的修饰器栈：15 个内置修饰器、事件时间轴，并且可以用脚本定义自己的修饰器。
ES 扩展方言
内置「Engine Custom ES」Lua 方言，额外提供约 70 个函数（相机、数组、着色器、菜单等），且不覆盖 Psych 原版回调。
跨平台
一次开发，可在 Windows、Android 与 HTML5 上运行；Android 端带虚拟按键与分区存储支持。
PowerPuff 主题 UI
飞天小女警风格的加载、待机与过场画面，另有自定义淡入淡出／方块转场，替换掉原版转场。
内置编辑器
谱面编辑器、角色编辑器、周目编辑器、对话编辑器与方块代码编辑器都随引擎一起提供。

常见问题

摘自 _content/home.md，更多内容见文档门户。

我的 Lua 脚本和 HScript 脚本（Parker 独有）应该放在哪？

它应该在 mods 文件夹中的特定文件夹中，每个文件夹将在不同的场景下执行脚本。

  • scripts — 一个全局文件夹，可以全局执行该 mod 的任何歌曲中的脚本。
  • data — 它应该在另一个文件夹中，这个文件夹就是歌曲的名字，它将在该歌曲中执行脚本。
  • stages（背景）— 它应该在另一个文件夹中，该文件夹是该背景的名称，将在该阶段执行脚本。
  • custom_events — 脚本应以事件命名，将在事件中执行脚本。
  • custom_notetypes — 脚本应以箭头类型命名，将在箭头类型上执行脚本。
我在哪里可以学习 Lua？

尝试阅读《Lua 编码基础》，它基本上解释了它的基础知识。如果你是新手，我会推荐你的！

哪里可以学习 Haxe（源代码）？

试着读一下 Haxe 官方介绍。阅读源码对编写 HScript 很有帮助。
